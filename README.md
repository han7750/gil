# road

소상공인을 위한 광고 영상 제작안을 무료로 만들어 드립니다.

**주소** → https://han7750.github.io/gil/

> 이름은 2026-08-07에 「길」에서 **road** 로 바꿨습니다.
> 폴더와 저장소 주소만 예전 이름(`gil`)을 그대로 씁니다 — 바꾸면 사이트 주소가 끊기기 때문입니다.

## 무엇을 해주나

가게 이야기를 적어 보내주시면, 짧은 광고 영상을 어떻게 만들지 정리해서 보내드립니다.

- **기획** — 가게를 한 줄로 정의하고, 광고 문구 3안
- **대본** — 컷마다 화면·촬영 방법·자막·대사
- **자막** — 영상에 넣을 자막만 따로 모아서
- **촬영 목록** — 준비물과 잘 찍는 요령
- **편집** — 캡컷·블로에서 누를 순서 그대로

모두 무료입니다.

## 어떻게 만들어졌나

파일 하나(`index.html`)로 된 사이트입니다. 서버가 없습니다.

신청서를 카카오톡으로 받고, 사람이 직접 만들어서 결과를 돌려드립니다.
자동 응답이 아니라 사람이 답합니다.

## 안전

- 결과는 **열쇠번호 4자리**로 잠깁니다. 번호를 모르면 열리지 않습니다.
- 대화는 1:1입니다. 다른 분이 볼 수 없습니다.
- 신청 내용은 어디에도 저장되지 않고, 카카오톡 대화 안에만 있습니다.

## 이 저장소에 있는 것

| 파일 | 무엇 |
|---|---|
| `index.html` | 사이트 그 자체. 이 파일 하나가 전부입니다 |
| `og.png` | 카톡·검색에 주소를 붙였을 때 뜨는 미리보기 그림 |
| `_검사.js` | 자체 점검. `node _검사.js` 로 52가지를 확인합니다 |
| `_화면시늉.js` | 가짜 브라우저로 화면을 진짜 그려봅니다. 깨지면 여기서 잡힙니다 |
| `_미리보기그림.js` | `og.png` 의 바탕(주황 · road 글자 · 차선)을 그리는 도구 |
| `_미리보기그림.ps1` | 그 위에 한 줄 글을 얹는 도구 (한글 글꼴이 필요해서 윈도우 쪽에서 그립니다) |
| `카카오채널-세팅.html` | 카카오 채널에 넣을 문구를 복사 단추로 정리한 화면 |
| `카카오채널-문구.md` | 위 화면의 문구 원본 |
| `CLAUDE.md` | 클로드 코드가 읽는 안내. 다른 컴퓨터에서도 맥락이 이어집니다 |

## 다른 컴퓨터에서 이어서 하려면

```
git clone https://github.com/han7750/gil
cd gil
claude
```

`CLAUDE.md` 를 클로드가 자동으로 읽어서, 이 프로젝트의 규칙과 주의사항을 알고 시작합니다.

**딱 하나만 손으로 옮기시면 됩니다 — 장부입니다.**

장부(열쇠번호 기록)는 브라우저 안에만 있어서 따라오지 않습니다.

1. 쓰던 컴퓨터에서 → 사이트 → 운영실 → 장부 → **백업 글 보기** → **백업 글 복사**
2. 그 글을 새 컴퓨터로 옮기기 (카톡으로 나에게 보내기, 메일, 아무거나)
3. 새 컴퓨터에서 → 운영실 → 장부 → 아래 칸에 붙여넣고 **붙여넣은 백업 되살리기**

> 운영실 비밀번호는 `index.html` 안에 있어서 **그대로 따라옵니다.** 다시 정할 필요 없습니다.

## 고치는 법

`index.html` 을 고치고 올리면 1~2분 뒤 사이트에 반영됩니다.

```
node _검사.js       # 52가지 자체 점검
node _화면시늉.js    # 화면이 실제로 그려지는지 확인
git add -A
git commit -m "무엇을 고쳤는지"
git push
```

주요 자리:

| 찾을 말 | 무엇인가 |
|---|---|
| `SITE_URL` | 이 사이트의 진짜 주소 |
| `CONTACT_DEFAULT` | 신청서를 받을 카카오톡 주소 |
| `TIERS` | 납기 종류. `locked: true` 면 못 고르게 잠깁니다 |
| `LENGTHS` | 고를 수 있는 영상 길이 |
| `REPLIES` | 카톡 답장 문구 모음 |

English is supported — press **EN** at the top right.
